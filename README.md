# Lagerprogram – källkod för ChatGPT

Detta offentliga repository innehåller en kompakt kopia av lagersystemets aktuella källkod.

## Så används materialet

Ge repositorylänken till ChatGPT eller anslut GitHub i ChatGPT. Koden finns i mappen codebase som numrerade textdelar. Varje originalfil börjar med en tydlig rad: FILE: sökväg.

## Omfattning

- 383 textbaserade käll- och konfigurationsfiler
- 9 textdelar för enklare AI-läsning
- frontend, API, delade bibliotek, tester och paketkonfiguration

## Avsiktligt uteslutet

Alla .env-filer, node_modules, cache, byggresultat, Git-historik, uppladdningar, exporter, bilder, PDF-filer och andra stora binärfiler.
